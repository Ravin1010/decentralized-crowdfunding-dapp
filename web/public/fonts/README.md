# Self-hosted font assets

Latin WOFF2 assets from Fontsource packages, version 5.3.0:

- `@fontsource-variable/manrope`: Manrope variable upright, weights 200–800.
- `@fontsource-variable/inter`: Inter variable upright, weights 100–900.
- `@fontsource/ibm-plex-mono`: IBM Plex Mono regular, weight 400.

Each family is licensed under SIL Open Font License 1.1. The corresponding original license and copyright notice is included alongside these files. Source: https://github.com/fontsource/fontsource. No font package is a runtime dependency.
